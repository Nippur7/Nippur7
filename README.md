## 🚀 Featured Project

### **[Multi-Domain RAG System](https://github.com/Nippur7/RAG_proyect_v1.0)** — Software Architecture & Requirements Knowledge Base

> Complete Retrieval-Augmented Generation system for semantic querying of Mermaid architecture diagrams and software requirements documents.

**Architecture:** Full ETL pipeline → Factory pattern parsing → Hierarchical semantic chunking (3 levels) → Metadata enrichment → BGE-M3 embeddings (1024D) → Qdrant vector search → SSE streaming bridge to AnythingLLM

**Key features:** Custom vector search client on Qdrant (no pip deps), chunk graph for context expansion, domain-specific prompt engineering, token-by-token SSE streaming, local memory fallback.

**Tech stack:** Python · Qdrant · llama.cpp · BGE-M3 · GGUF · AnythingLLM · Mermaid · REST API · SSE
